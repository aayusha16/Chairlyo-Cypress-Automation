# Chairlyo Cypress Automation

Cypress end-to-end automation project for testing the **Chairlyo** web application.

## 🛠️ Tech Stack

* Cypress
* JavaScript
* Node.js
* XPath
* Git & GitHub

## 🧪 Test Modules

* **Login** – Login and validation scenarios
* **Add Branch** – Branch creation and form validation
* **Add Waiting** – Waiting line and form validation

## 🚀 Run Tests

Install dependencies:

```bash
npm install
```

Open Cypress:

```bash
npx cypress open
```

Run all tests:

```bash
npx cypress run
```
